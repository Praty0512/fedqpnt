## Purpose recap (from task)
1. CALIBRATION/VALIDATION — fit sim noise model (white-noise sensitivity, bias-instability floor, drift, dead time, cycle rate) to ADEV of real records.
2. NOISE REPLAY — detrend real static records, extract residual noise, block-bootstrap replay as stochastic part of simulated cold-atom accelerometer ("real-noise" mode).
Truth dynamics stay simulated (no public quantum-sensor dataset has attacked GNSS on a moving vehicle).

## Fallback / other quantum-navigation datasets (explicitly NOT atom-interferometer)

- MIT/DAF MagNav dataset (#4 above) — classical magnetometer + classical IMU/GPS, airborne, moving platform. Genuinely real and downloadable, well documented via GitHub (MagNav.jl) and Zenodo. Useful only as an analogy/engineering reference for "real navigation-grade dataset with attacked-GNSS-style moving platform" structure, NOT for cold-atom accelerometer noise. Flag clearly as non-fit if used.
- IGETS superconducting gravimeter network (#5 above) — real, static, long-duration (decades at some stations), but wrong sensor type (SG, not AI). Best use: source of "known signal" (Earth tides, ocean loading, polar motion) time series if we ever need a template to synthesize/validate the detrending step of our noise-replay pipeline, or to sanity check tidal-removal code before applying it to any future AI gravimeter record.
